Coding for my thesis for Georgetown University (MPP).
Adviser: Leeann Comfort

Data from New York's SPARCS data set on hospital inpatient discharges, County Health Rankings and Roadmaps (New York), and NASHP's HCT data set. 

Additional data not used in thesis from AHRQ. 

Final product uploaded as Quarto files (html files): for_rendering and HCRIS_added_data. 

Note: Code from HCRIS_added_data may not run through without revisions for users because I initially did some manual cleaning due to facility identifiers not matching between data sets. You can likely work around that now that I have added more data sets and crosswalk data from other sources.

Data sets:

1. NASHP High Cost Tool: https://tool.nashp.org/
2. County Health Rankings and Roadmaps (New York): https://www.countyhealthrankings.org/health-data/new-york/data-and-resources
3. SPARCS Major Potentially Preventable Complications by Hospital: https://health.data.ny.gov/Health/Hospital-Inpatient-Discharges-SPARCS-De-Identified/s3du-3m47/about_data  
4. Agency for Healthcare Research and Quality U.S. Compendium: https://www.ahrq.gov/chsp/data-resources/compendium.html
5. HUD Zip Code Crosswalk: https://www.huduser.gov/portal/datasets/usps_crosswalk.html
6. USGS Geographic Names Information System: https://www.usgs.gov/us-board-on-geographic-names/download-gnis-data
